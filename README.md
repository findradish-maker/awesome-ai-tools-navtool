## 常见问题

<details>
<summary><strong>这些工具都免费吗？</strong></summary>

清单包含在线服务、桌面工具、开发框架和学习资源。免费范围、试用额度、订阅与 API 费用各不相同，请以各工具当前说明为准。

</details>

<details>
<summary><strong>为什么工具名称链接到探兔？</strong></summary>

探兔介绍页提供中文用途说明和工具入口，方便先了解再选择。每行右侧保留直接访问产品或项目的链接。

</details>

<details>
<summary><strong>英文版和中文版内容一样吗？</strong></summary>

两个版本包含相同的 120 个工具、16 个分类与链接。英文版翻译了工具用途、导航和配图；探兔网站及工具介绍页目前以中文为主。

</details>

<details>
<summary><strong>这是网站源码仓库吗？</strong></summary>

当前公开内容为精选文档、JSON 数据与展示素材。线上网站的部署源码不在本次发布范围。

</details>
